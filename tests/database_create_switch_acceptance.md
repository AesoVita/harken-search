# 新建与切库真实包回归

所有库及音频只放本卡 D:/Aris-QA 隔离目录。使用本卡带编译时隔离根的 HarkenSearch.exe。不得在用户数据上做覆盖测试。

1. 在默认位置新建 Harken Search，导入一个合成 WAV，等待扫描结束，确认列表为 1 项。
2. 再打开新建窗口，填同名 Harken Search，勾选覆盖并点覆盖创建。期望空库，执行下列断言得到 0；旧版本会得到 1（已复现）。
3. 用 A/B 两个独立库，A 有 1 个文件，B 空库；从菜单或库选择器来回切换，各次检查身份和数量。
4. 用进程外只读句柄占用要覆盖的测试库，尝试覆盖。期望可见错误、旧内容不变，不得伪报创建成功。
5. 使用损坏数据库、不可访问路径、测试包隔离根以外的独立测试路径。期望明确失败原因，保留旧库；重复提交不得删除文件。
6. 在隔离实例扫描期间尝试创建/切换，期望拒绝并保留原库。
7. 真实界面截图和操作结果交用户确认，静态断言不代替前端确认。
8. 让右侧封面预览加载完成再重复第 2、3 步至少两轮，确认封面后台连接随切库释放并能重新加载；否则只有未启动封面任务的空白实例通过，不能算完整验证。正常模式和编译时隔离模式分别执行。
9. 额外传入实际进程的 --pid，检查窗口标题的文件数量也立即变成目标库数量；新库列表为 0、标题仍为旧值时必须失败。

```powershell
python tools/database_switch_acceptance.py --runtime <隔离根>/profile/runtime --exe <实际EXE> --database <目标库>/main.db --count 0 --report <证据目录>/create-result.json
python tools/database_switch_busy_acceptance.py --runtime <隔离根>/profile/runtime --switch-to <隔离根>/databases/B/main.db --report <证据目录>/busy-result.json
```

第二个脚本会在测试根生成 5000 个合成 WAV，启动真实扫描后重复切换两次，检查拒绝及库身份不变，并停止扫描；当前库与目标库必须不同且都位于测试根。创建失败后确认弹窗仍在，切换失败确认波形停靠时也能直接看到错误，不依赖隐藏状态栏。

测试包隔离目录限制须保留；给用户正常安装使用的包不得携带测试用编译时隔离根。
