引言

心动网络股份有限公司（以下简称“我们”或“心动”）作为Harken Search的运营方，深知个人信息对您的重要性。本隐私政策说明我们在您使用本产品时，如何收集、使用、存储、共享、保护和删除您的个人信息，以及您如何行使相关权利。

在您接受我们的服务前，请您仔细阅读并充分理解本隐私政策。在您点击“同意”本政策或使用本产品及/或相关服务后，即适用本政策，我们将按照本政策来收集、使用、存储和保护您的相关信息。如您不同意接受本政策的任意内容，或者无法准确理解相关条款的含义，请勿进行后续操作。

一、我们如何收集和使用个人信息

我们会基于实现产品功能、保障安全、处理您的请求及履行法定义务的需要处理个人信息。除法律另有规定或取得您的单独同意外，我们不会将您的个人信息用于与上述目的无关的用途。

1.Harken Search 本地功能

Harken Search 可在您的设备本地扫描、索引、搜索、试听和管理音频素材，并可能处理文件路径、文件名、音频元数据、波形、响度、声学特征、标签、描述、搜索词、筛选条件、相似度结果、转写文本、临时文件及本地数据库。这些信息用于建立和维护您的本地声音库、实现搜索、试听、分析、转写和元数据管理功能，通常不会发送至心动服务器。

如您使用元数据回写功能，Harken Search可能修改原始音频文件中的元数据。请您在操作前自行确认文件及备份。

当您使用更新检查、自动更新或官方下载功能时，Harken Search 会根据本机操作系统类型，优先访问 GitHub 上的公开更新清单或发布地址，以取得适配的安装包或更新包；当 GitHub 链路不可用或不畅通时，Harken Search可能切换至 OSS 等备用下载地址。本地更新适用性判断及完整性校验均在您的设备本地完成。

如您自行将局域网 NAS 或其他本地网络位置添加为声音库或存储位置，本产品可能在该等位置处理文件路径、文件名、音频元数据、波形、标签、索引、转写文本及本地数据库信息。该等信息用于在您指定的存储上提供搜索、试听、分析和元数据管理，通常保存在该等存储或您的设备上，不会因此上传至心动服务器。NAS 地址、账号和密码由您自行配置和保管，我们不会要求您将该等凭证提交给我们。

2. 反馈、客服、安全报告和社区协作

当您主动提交反馈、客服请求、崩溃报告、安全报告、Issue、Pull Request、Discussion 或其他社区内容时，我们可能处理您主动提交的姓名或昵称、联系方式、反馈描述、附件、系统和版本信息、日志、崩溃报告及沟通记录，用于答复请求、排查问题、维护项目安全及进行社区治理。

请不要在反馈、日志、公开社区内容或附件中提交无关个人信息、商业秘密、未授权素材、账号密码、API Key、访问令牌、签名私钥或其他敏感凭证。公开代码托管平台上的提交、评论、提交记录、姓名、邮箱和附件可能依据该平台规则长期公开可见。

二、我们处理信息的法律基础

在适用法律要求我们说明处理依据的地区，我们会基于下列一种或多种依据处理个人信息：

• 为履行与您的合同或采取合同订立前措施所必需；

• 取得您的同意；

• 履行法定义务；

• 保护您或他人的重大合法权益；

• 或为我们的合法利益所必需且不对您的权益造成不当影响。

对于依法需要单独同意或明示同意的处理活动，我们将依法另行征得您的同意。

三、我们如何委托处理、共享、转让和公开披露信息

1. 委托处理

我们可能委托云服务、下载与更新基础设施、反馈系统、客服、数据安全或其他服务提供方代表我们处理必要信息。我们会要求受托方按照我们的要求、适用法律及安全措施处理信息，并限制其处理范围。

2. 第三方服务

在您主动选择、连接或调用第三方服务时，为执行您的指令，相关信息可能提供给您选择的第三方。第三方如何处理信息，适用其自身条款和隐私政策。

根据相关法律法规及国家标准，在以下情形中，我们可能会依法收集并使用您的个人信息而无需征得您同意：

• 与履行法律法规及行业主管部门规定的义务相关的；

• 与国家安全、国防安全直接相关的；

• 与公共安全、公共卫生、重大公共利益直接相关的；

• 与犯罪侦查、起诉、审批和判决执行直接相关的；

• 出于维护您或其他个人的生命、财产等重大合法权益但又很难得到您本人同意的；

• 您自行向社会公众公开的个人信息；

• 从合法公开披露的信息中收集的个人信息，例如：合法的新闻报道、政府信息公开等渠道。

3. 转让

原则上，我们不会向其他组织和个人转让您的用户信息，但在我们与其他法律主体发生合并、收购或破产清算情形，或其他涉及合并、收购或破产清算情形时，如涉及到用户信息转让，我们会要求新的持有用户个人信息的公司、组织继续受本政策的约束，否则我们将要求该公司、组织和个人重新向您征求授权同意。如涉及破产且无承接方的情形，我们将依法对数据进行删除处理。

4. 公开披露

我们承诺对您的信息进行严格保密，如确需公开披露时，除法律法规另有规定外，我们会向您告知公开披露的目的、披露信息的类型及可能涉及的敏感个人信息，并征得您的单独同意。

四、信息存储及处理地点

Harken Search以本地处理为主，您扫描、索引、搜索、试听或管理的音频文件、文件路径、索引、标签、元数据、转写文本、临时文件、本地数据库、缓存、本地日志和配置，通常保存在您的设备上。

当您使用 GitHub、OSS、CDN、代码托管或官方下载与更新等第三方服务时，相关服务提供商可能根据其自身的服务条款和隐私政策，在其所在地区或其他地区处理必要的网络访问信息以及您主动提交的内容。心动不控制该等第三方服务的数据存储地点、处理方式或保存期限。

我们将根据适用法律，对我们实际控制或处理的个人信息采取相应的告知、授权、保护和安全措施。

五、信息存储期限

除法律法规另有要求，或为处理争议、投诉、安全事件所必需外，我们仅在实现本政策所述目的所需的最短期限内保存个人信息。

您的音频文件、索引、标签、元数据、转写文本、临时文件、本地数据库、缓存、本地日志和配置通常存储在您的设备上，保存期限由您控制。如您使用元数据回写功能，对原始音频文件的修改也保存在您的设备上，保存期限由您控制。

您指定的局域网 NAS 或其他本地网络位置上的音频、索引和数据库，通常保存在该等存储上，保存期限由您控制。

您主动提交的反馈、客服记录、安全报告，以及由我们控制的官方下载与更新服务产生的必要服务日志，将根据相应业务需要及适用法律保存。

六、我们如何保护信息

我们一直都极为重视保护用户的个人信息安全，为此我们采用了符合行业标准的安全技术及组织和管理等保护措施以最大程度降低您的信息被泄露、毁损、误用、非授权访问、非授权披露和更改的风险。包括：

● 技术措施

1、使用加密技术以确保数据传输的保密性；

2、提供多种安全功能以保护您的信息安全；

3、使用去标识化、匿名化等合理可行的手段保护您的个人信息；

4、使用受信赖的保护机制防止数据遭到恶意攻击。

● 管理措施

1、建立数据处理和访问制度，以防未经授权的人员访问我们的系统；

2、对员工进行安全教育与培训，签署保密协议，加强员工对于保护个人信息安全重要性的认识；

3、成立专门的数据安全部门，并制定个人信息安全事件的应急预案；

4、定期组织安全应急预案演练，预防此类安全事件发生；

5、若发生个人信息泄露等安全事件，我们会启动应急预案，阻止安全事件扩大，并通过推送通知、公告等形式告知您。

我们将依法采取与风险相适应的技术和管理措施保护个人信息，但互联网、通信网络和信息存储系统不存在绝对安全。如果我们的物理、技术、或管理防护设施遭到破坏，导致个人信息被泄露、篡改或丢失，导致您的合法权益受损，我们将按照法律的规定第一时间通知您，并承担相应的法律责任。

七、您的权利

在适用法律规定的范围内，您有权就我们实际处理的、与您有关的个人信息，依法行使查阅、复制、更正、补充、删除、撤回同意及获取处理规则说明等权利。

Harken Search 以本地处理为主，且无账号体系。您能够行使上述权利的范围，取决于相关信息是否由我们控制，以及我们能否将该等信息与您合理关联。

1. 保存在您设备上的信息

您在本机扫描、索引、搜索、试听或管理的音频文件、文件路径、文件名、音频元数据、波形、标签、描述、搜索词、筛选条件、相似度结果、转写文本、临时文件、本地数据库、缓存、本地日志、Crash Dump 和配置，通常仅存储在您的设备上。您可以通过产品功能、系统设置或手动删除本地文件进行查阅、更正、导出或删除。

如您使用元数据回写功能，相关修改发生在您本机的原始音频文件中，也应由您自行在本机查阅、更正或处理。

该类信息通常不会上传至心动服务器，我们通常无法直接查阅、更正、删除或恢复。

2. 您主动提交给我们的信息

对于您主动提交至反馈、客服或安全报告系统的信息，包括反馈内容、联系方式、昵称、操作系统、RAM、CPU、GPU、产品版本，以及您主动附带的日志或崩溃报告，您可以通过本政策列明的联系方式申请查阅、复制、更正或删除。

若您未提供联系方式或其他可识别信息，我们可能无法准确定位相应记录。提出请求时，可以提供提交时间、标题、内容关键词或反馈编号，以便查询。

3. 网络访问日志

对于官网、OSS、CDN 或其他由我们控制的下载与更新服务产生的网络访问日志，您可以依法提出查阅、更正或删除请求。实际处理范围取决于该等日志是否仍在保存期限内、能否与您准确匹配、是否由我们控制，以及是否存在法定留存或安全审计要求。

由第三方服务商独立保存的日志，可能需要按照其规则处理。

4. 第三方服务中的信息

您向 GitHub 等代码托管平台提交的 Issue、Pull Request、Discussion、评论或提交记录，由相应平台按其规则处理。请您通过该等第三方提供的渠道行使权利。我们通常无法代为查阅、更正或删除其控制的信息。

5. 如何提出请求

您可通过 harken-support@xd.com 提出权利请求。为核验请求人身份、定位相关记录并防止他人冒用，我们可能要求您提供合理必要的说明。我们将在适用法律规定的期限内答复；依法需要继续保存、无法核验身份，或请求超出我们控制范围的，我们将向您说明理由。

您可以通过停止使用本产品、关闭自动更新或不再提交反馈，撤回对后续处理的同意。已按法律要求保存，或已由您自行提供给第三方的信息，按本政策及其他适用规则处理。

八、未成年人保护

本产品主要面向游戏音频设计、游戏开发、音频后期等专业场景，不以未成年人为主要服务对象。

如果我们发现未满18周岁的人使用了本产品，我们将采取合理措施限制其继续使用，并在法律允许的范围内删除或匿名化处理相关个人信息。未成年人本人或其监护人可通过本政策约定之联系方式向我们反馈。
