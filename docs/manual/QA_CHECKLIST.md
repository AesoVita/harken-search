# Harken Search QA 检查说明

## 要查哪些部分

本包来自 `qa/current`，用于检查当前开发版本。包内版本与 `harken-runtime-pair.json` 记录的源码提交必须一致。

## 怎么查

在隔离测试环境中启动 `Airs/HarkenSearch.exe`，使用测试音频检查扫描、搜索、预览和本次改动涉及的操作。使用仓库提供的对应自动测试核对结果。

## 怎样算过

自动测试通过且实际操作符合本次任务的验收要求。仅有构建成功或打开程序不能替代功能验收。

## 这次不查什么

本包不是正式安装器，不证明正式签名、发布、自动更新或网站同步已完成。这些流程分别留存验证结果。

## 没通过时留下什么

记录源码提交、程序路径与 SHA256、复现步骤、实际结果和必要日志。界面问题保留真实截图；测试不使用日常音频库和设置。
