# 明亮雾蓝实机预览

用户确认明亮、低饱和、色块低对比的蓝色效果图后要求实机版本。只修改现有海军蓝（LapisBlue）主题，不新增主题或改变布局与业务。筛选器为白色；工作区、信息区和播放区域仍明显为蓝色，以相邻色阶区分。低对比指面板之间，不指文字。

主题表集中定义各模块底色、文字和选中色。主区域亮度保持在0.35到0.8，蓝色分量比红色至少高0.08；与结果区的面板对比小于1.6。常用正文、筛选器与元信息标签保持4.5以上。保留播放数值撤框与空态按钮清晰度修正作为本卡预览依赖，详细提交记录在卡片。

先运行 TestMistBlueTheme 验证原主题不能满足明亮蓝与白筛选器要求，再调整配色，运行相关颜色测试和真实包截图。实际空态与合成音频场景均使用本卡固定隔离数据；不占用用户鼠标。五主题巡检用于检查其他主题不受影响。输出本卡分支测试包，用户看到实际截图前不记实机验收通过。

独立复核发现旧派生规则把深色图标强调色也用作按下/选中底色，与新深色文字相撞。MistBlueChrome 只在内置 LapisBlue 应用主题时将按钮按下、标签页悬停/选中、列表按下背景改用浅蓝；结果页标签保留深色正文，不再混浅。回归覆盖生产映射及文字对比。主题编辑器的自定义配色路径不在本次内置主题预览范围。
