# Security Policy

This policy covers Harken Search.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue, discussion, pull
request, or commit message.

The primary public channel is GitHub private vulnerability reporting on this
repository (Security advisories / Report a vulnerability), when that feature
is enabled. If it is not enabled, external reporters may use the verified
private fallback harken-support@xd.com, and only for that case. Reporters
working inside XD should still use XD's approved internal security incident
process. Do not invent another email address or team handle.

Include the affected revision, impact, reproduction conditions, and the
minimum evidence needed to investigate. Do not include credentials, personal
data, user libraries, or proprietary third-party material.

## Response and disclosure

Repository maintainers coordinate triage with the authorized security
response role. Security-sensitive fixes remain private until the response
owner approves disclosure and release timing. Public advisories and release
notes must not precede that approval.
